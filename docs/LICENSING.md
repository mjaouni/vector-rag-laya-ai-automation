# Ownership and third-party licensing

The owner explicitly chose **"Publish without a license for now"** on 26 October 2026. Accordingly, no application LICENSE file or MIT/Apache grant has been added for project-owned code or documentation. Public visibility alone is not a general permission to redistribute or relicense it. A license can be added later at the owner's direction.

No third-party application source or model checkpoint is vendored. Dependencies are installed from their own distributions and remain governed by upstream terms. Key upstream references to review before redistribution or deployment:

| Dependency/model | Upstream licensing reference |
|---|---|
| Laya | [Model card](https://huggingface.co/convaiinnovations/laya), tagged Apache-2.0 |
| MiniLM | [all-MiniLM-L6-v2 model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) |
| Qwen2.5:7b | [Qwen2.5-7B-Instruct model card](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) |
| n8n | [Sustainable Use License explanation](https://docs.n8n.io/sustainable-use-license/); do not assume it is MIT/Apache |
| Ollama | [Upstream repository](https://github.com/ollama/ollama) |
| Qdrant client | [Upstream repository](https://github.com/qdrant/qdrant-client) |
| Mailpit | [Upstream repository](https://github.com/axllent/mailpit) |

An eventual license for project-owned integration code does not change dependency/model terms or grant ownership of third-party software. This is an inventory of licensing boundaries, not a legal compatibility opinion.
